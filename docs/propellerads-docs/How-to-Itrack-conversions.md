# How can I track conversions?

```
Written by Paola
Updated over 8 months ago
```
Keeping track of conversions is extremely important because it determines the
campaign's success.
Conversion tracking is used to measure the results of advertising activities:

```
It is possible to determine how many users completed the target action on the
target page after clicking on the ad
It lets the advertisers see which ads and campaigns bring paying customers
Advertisers understand which campaigns generate revenue and which are simply
draining resources
```
As a self-service advertiser in PropellerAds, you can set server-to-server (S 2 S)
campaign tracking options.


S 2 S tracking is characterized by high accuracy and reliability of data transfer. Such
tracking transfers conversion information directly from the advertiser's server to the
advertising network or tracker server. The method is reliable for conversion tracking,
but it requires some technical knowledge to set up.

At PropellerAds, advertisers can use the conversion tracking feature free of charge and
get all the insights they need to improve their campaigns' performance. Advertisers can
see all created campaigns through one centralized dashboard and adjust various
settings that ultimately impact the sales funnel.

The S 2 S tracking can be set inside the Tracking Tab of the PropellerAds dashboard.


With the help of tracking, you can check different parameters inside the campaign.
You can use the different variables (dynamic tags/tokens) to track interested data
through your URL and your own tracking system. To track the conversion, please use
the **${SUBID}** - a unique ID for tracking conversions macro. Other tokens can be found
in the article about S 2 S tracking.
Please refer to this manual to learn how to integrate PropellerAds' S 2 S conversion
tracking. In addition, you may check out PropellerAds' series of video guides about S 2 S
tracking.

_Note: Please get in touch with your account manager if you are a fully
managed advertiser and want to use pixels or postback to track conversions._

PropellerAds conversion tracking helps advertisers measure the results of their
advertising campaigns and improves their effectiveness by optimizing traffic and
allocating resources to the most promising sources of conversions.
